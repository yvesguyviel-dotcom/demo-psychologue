# Projet : site de démonstration d'un praticien (Astro)

## Contexte
- L'utilisateur (Yves) n'est pas développeur. Réponds en français simple, résumé de 5 lignes maximum.
- Régime : P (psychologue, titre protégé, information avec mesure). Lance .\verifier.ps1 -Regime P
- Ce site est une DÉMO : il reste en noindex (jamais indexé).

## Ce que tu peux faire
- Modifier les fichiers de src/ et public/ pour réaliser la demande.
- Pour une demande de texte : modifie UNIQUEMENT les textes, jamais le design, la structure ni la configuration.
- Ne modifie jamais package.json, pnpm-lock.yaml, astro.config.mjs ni pnpm-workspace.yaml sans demande explicite.
- Si un texte à remplacer n'existe pas exactement, ne modifie rien pour ce point et signale-le.
- Traite aussi les variantes (casse, accents, phrase plus longue).

## Après chaque modification (obligatoire)
1. Lance : .\verifier.ps1 et montre le résultat BRUT.
2. Lance : pnpm build et montre les 5 dernières lignes.
3. Montre : git --no-pager status --short
4. N'exécute git add, git commit et git push QUE si la demande contient le mot "publie". Sinon arrête-toi et demande.
5. Ne dis jamais "terminé" sans avoir montré ces résultats.

## Règles de contenu (régime A)
- Aucun avis, témoignage, note, superlatif, comparatif, promesse de résultat, slogan.
- Aucun lien commercial cliquable (le crédit du créateur du site est en texte simple).
- Aucun nom de marque ni photo de produit.
- Ce qui n'est pas vérifié est marqué "à compléter".
- Rendez-vous : lien vers une plateforme externe, aucun formulaire à texte libre.
- Mentions légales et politique de confidentialité présentes.
- Aucune phrase sur le remboursement ou les mutuelles.
